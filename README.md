# PRISM: Privacy Preserving Runtime Isolation for Secure Multimodal AI

This project demonstrates a limited implementation of the PRISM framework on the Yahboom ROSMASTER X3. The X3 comes with a Jetson Orin Nano 8GB and an Orbbec Astra Pro Plus camera which supports colour, depth and infrared channels. This project goes through an OP-TEE with secure I/O channel setup.

Read [this](/OVERVIEW.md) for an overview of the project, and [this](/OVERVIEW.md) for detailed walkthrough of the implementation.
